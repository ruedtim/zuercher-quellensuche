# Regierungsratsbeschlüsse

| | |
|---|---|
| **Kürzel** | RRB |
| **Inhalt** | Beschlüsse der Zürcher Regierung (Regierungsrat, bis 1831 Kleiner Rat) seit 1803 |
| **Hier durchsuchbar** | 1803–1995 digitalisiert (Edition des Staatsarchivs, mit Faksimile); ab 1. Oktober 2008 aus den Open Data von zh.ch, laufend ergänzt (Volltext, ohne Faksimile) |
| **Lücke** | 1996 bis September 2008 |
| **Offizielle Beschlüsse ab 2008** | [zh.ch](https://www.zh.ch/de/politik-staat/gesetze-beschluesse/beschluesse-des-regierungsrates.html) |

## Auf dieser Plattform

- Je Beschluss ein Dokument; über 500'000 sind es insgesamt, der grösste Bestand der Zentralen Serien.
- **Lücke:** Suchen und Zeitleisten zeigen für 1996 bis September 2008 keine Regierungsratsbeschlüsse. Das sagt nichts über das Thema aus.
- **Schutzfristen:** Beschlüsse, die einer laufenden Frist von 30 oder 80 Jahren unterliegen, hat das Staatsarchiv nicht publiziert; ab 2008 sind es die als öffentlich eingestuften Beschlüsse.
- **Ab 2008** verweist die Detailansicht auf das Original-PDF auf zh.ch.
